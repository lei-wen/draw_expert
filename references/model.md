# 模型与计算

## 参数估计

有完整联赛历史样本时，可使用：

log(μ) = 截距 + 主场优势 + 主队进攻效应 + 客队防守失球效应
log(λ) = 截距 + 客队进攻效应 + 主队防守失球效应

通过和为零或基准球队约束保证可识别性。小样本采用正则化或向联赛均值收缩；训练、调参及验证按时间分割。近期权重不能利用预测之后的信息。简化估计应明确进失球如何合成及使用的联赛主客场基准，不能将任意经验值称为最大似然拟合。历史交锋不重复计入已有比赛样本。

## 联合分布

设独立 A~Poisson(μ-κ)、B~Poisson(λ-κ)、C~Poisson(κ)，X=A+C、Y=B+C。
约束 μ≥0、λ≥0、0≤κ≤min(μ,λ)。μ、λ 是两队边际均值，不能再额外加 κ。

P(X=x,Y=y) = exp[-(μ+λ-κ)] × Σ[k=0..min(x,y)]
 (μ-κ)^(x-k) (λ-κ)^(y-k) κ^k / [(x-k)! (y-k)! k!]

Cov(X,Y)=κ；μλ>0 时 ρ=κ/sqrt(μλ)。只支持非负相关，不把这个共享成分模型与 Dixon–Coles 的低比分修正混为一谈。κ 应联合拟合；相关性不足以估计时用 κ=0 并说明限制。

主胜=sum(x>y)，平局=sum(x=y)，客胜=sum(x<y)。扩大矩阵直至遗漏质量<1e-6；披露截断质量，不以归一化掩盖大量遗漏。

附带脚本采用无第三方依赖的递推与共享成分混合：

```bash
python3 scripts/score_probs.py --mu 1.1 --lam 0.9 --kappa 0
python3 scripts/score_probs.py --mu 1.1 --lam 0.9 --kappa 0.1 --odds 2.5 3.1 2.9
```

命令中数字仅为运行示例，不是默认参数或真实赛事预测。μ、λ、κ必须来自本次分析。脚本范围为每队均值≤30（超出时应检查足球数据口径），输出概率单位为0–1、差值单位为百分点。输出包括两种比分排名与矩阵遗漏质量；`kappa=0` 时仅代表独立基线。

## 市场比较

对同一市场同一公司的十进制赔率 oH、oD、oA（均>1）：
q_i=(1/o_i)/(1/oH+1/oD+1/oA)。这是比例去水法，不是真实概率估计的保证。
平局概率差（百分点）=100×(pD-qD)。没有赔率时省略；不同时间、公司或让球口径不得直接拼接。

## 稳健性与复盘

敏感性分析说明参数变化范围及理由；没有统计推断方法，不称其为置信区间。固定边际均值改变 κ 的效果与固定独立成分均值不同，不能笼统声称“相关性越高越该推荐平局”。同样不能把模型比市场高几个百分点自动解释为收益保障。

保存预测时点可获得的数据，滚动做样本外验证。评估概率校准、Brier 分数或对数损失，比较联赛平局率或独立泊松基线。需要收益复盘时另外说明赔率时点、结算规则、费用与样本量，不以命中率替代校准。
